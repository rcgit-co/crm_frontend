# v3 — Soft Neumorphism (реализованное направление)

> По запросу «совсем другой дизайн» направление сменено со светлого
> Exaggerated Minimalism (см. MASTER.md) на **Soft Neumorphism** (skill: Evolved
> Neumorphism, WCAG AA+). Меняется не цвет, а **визуальный язык**: рельеф вместо
> карточек-с-границами, монохром + единственный акцент, тактильные тени.

## Принцип
Все поверхности — одного тона; глубина создаётся двумя мягкими тенями
(свет сверху-слева, тень снизу-справа). Выпуклые элементы «подняты», поля и
активные состояния «вдавлены». Тёмных зон нет — единая монохромная сцена.

## Токены
```
База/карта:  #E6E9F0   (всё одного тона)
Текст:       #2B3242 / #495265 / #596178
Акцент:      azure #3B6FE0 (единственный), soft #DDE6FB
Тени:        --nm-l #FFFFFF, --nm-d #C2C8D6
  raise:  6px 6px 14px d, -6px -6px 14px l
  press:  inset 4px 4px 9px d, inset -4px -4px 9px l
Радиусы:     14 (контролы) / 20–26 (панели) / 999 (пилюли)
Шрифт:       Nunito (скруглённый, тактильный; кириллица ✅) — и заголовки, и текст
```
Тёмная тема — графитовый монохром (#2A2E38) с теми же неоморфными тенями.

## Компоненты
- **Card/Tile:** выпуклые (`--nm-raise`), без границ.
- **Button:** выпуклая; hover — выше, active — вдавлена. Primary — azure-заливка.
- **Input/Select:** вдавленные (`--nm-press`); фокус — кольцо azure.
- **Badge:** мягкая пилюля с лёгким inset.
- **Sidebar:** светлый, активный пункт «вдавлен» + azure-текст/иконка.
- **Topbar:** светлый, мягкая нижняя тень; кнопки (тема/бургер) выпуклые.
- **Bottom-nav (моб.):** активный пункт вдавлен.
- **Login/Register:** выпуклая карточка по центру на монохроме (без тёмной сцены).

## Применение
Реализовано глобально в `src/styles.css` + перестроены `AppLayout`, `AuthShell`,
`BrandLogo`, `DashboardView`. Остальные страницы наследуют язык через базовые
компоненты (card/input/button/badge/table) и будут донастроены поэлементно.
