# Страница: Клиенты (override Master)

**Цель:** база лидов/контактов + профиль клиента с историей.

## Блоки

### 1 — Шапка
H1 «Клиенты» + caption «Лиды и контакты агентства · N из M». Primary «+ Клиент».

### 2 — Тулбар-фильтр (карточка)
Поиск (ФИО/телефон/email) + селект статуса. Сброс — через пустой результат.

### 3 — Список (таблица → карточки на мобиле)
Колонки: Клиент (аватар с кольцом статуса + имя-ссылка), Контакты (телефон/email с line-иконками), Статус (бейдж с точкой), Источник, Действия (В контакт / Изм.).
- Аватар-кольцо: contact→ok, lead→warn.
- ≤640px: «лейбл над значением», контакты в столбик.

### 4 — Форма (модалка)
Фамилия, Имя*, Отчество, Телефон (маска +7), Email (валидация), Статус, Источник.
Инлайн-ошибки; disabled-кнопка с подсказкой «Укажите имя».

### 5 — Профиль клиента (wide-модалка)
- **Шапка профиля:** крупный аватар, статус-бейдж, контакты (иконки), «Изменить».
- **Две колонки:** Теги + Взаимодействия (таймлайн: тип, summary, дата, точки) | Заметки (карточки).
- Быстрое добавление тега/взаимодействия/заметки инлайн.

## Состояния
- Empty (база пуста) vs «Ничего не найдено по запросу …» + сброс фильтров.
- Loading: скелетон-таблица; профиль — скелетон-блок.

## Компоненты
ClientTable, ClientForm(Modal), ClientProfile(Modal), Timeline, Avatar.
