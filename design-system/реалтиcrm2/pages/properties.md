# Страница: Объекты / Каталог (override Master)

**Цель:** каталог недвижимости как премиальные листинги.

## Блоки

### 1 — Шапка
H1 «Объекты» + caption «Каталог · N из M». Primary «+ Объект».

### 2 — Тулбар-фильтр (карточка)
Поиск, Тип, Комнаты (1+…4+), Цена от/до, Статус. Сброс через пустой результат.

### 3 — Грид карточек (auto-fill, minmax 264px)
**Карточка-листинг:**
- **Обложка** (~116px): мягкий градиент по типу (flat→brand, house→ok, commercial→accent, land→warn) + тонкая сетка-паттерн + крупная line-иконка типа.
- Оверлеи: статус-бейдж (слева), чип типа (справа).
- Тело: заголовок, **цена** (бренд, крупно, таблярно), спеки с line-иконками (комнаты/площадь/этаж), адрес с пином.
- Действия: селект статуса + «Изм.».
- Hover-поднятие; вся карточка ощущается интерактивной.

### 4 — Форма (модалка, wide)
Название*, Тип, Комнаты, Площадь, Этаж/Этажность, Отделка, Цена (разряды), Адрес, Описание.

## Состояния
Empty vs «Ничего не найдено» + сброс; скелетон-карточки; error.

## Адаптив
≤600px — 1 колонка; тулбар переносится.

## Компоненты
PropertyCard, PropertyForm(Modal), MoneyInput, Icon(type/bed/ruler/layers/pin).
