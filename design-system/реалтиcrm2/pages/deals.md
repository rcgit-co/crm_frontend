# Страница: Сделки / Канбан (override Master)

**Цель:** вести сделки по стадиям, перетаскивать, видеть суммы. Данные — герой.

## Блоки

### 1 — Шапка (spread)
- H1 «Сделки» + caption-подсказка («Перетаскивайте карточки…»).
- Primary «+ Новая сделка» (иконка plus).

### 2 — Сводка доски (полоса-карточка)
- Три метрики через тонкие разделители: Всего сделок, Общая сумма (бренд, крупно, таблярно), Стадий.

### 3 — Доска (горизонтальный скролл)
- Колонки-стадии (ширина ~290px): сверху тонкая цветная полоса-акцент + точка, заголовок, счётчик-пилюля, сумма стадии.
- **Цвета стадий:** new→синий, in_progress→brand, deal→ok, archived→neutral.
- Подсветка колонки при drag-over (рамка-акцент + кольцо).
- Индикаторы прокрутки: затухание краёв + стрелки (скрыты на мобиле).

### 4 — Карточка сделки (draggable)
- Заголовок (2 строки max), **сумма** (бренд, крупно, таблярно).
- Связи строками с line-иконками: клиент, объект.
- Футер: дата создания + аватар ответственного (инициалы).
- Hover-поднятие + смена границы; состояние dragging (полупрозрачность, лёгкий наклон).
- Пустая стадия → пунктирная зона «Перетащите сюда».

### 5 — Модалка создания
- Поля: Название*, Сумма (с разделением разрядов), Стадия, Клиент, Объект, Ответственный (manage), Комментарий.
- Пустые селекты → подсказка «Сначала добавьте…».
- Disabled-кнопка → подсказка «Введите название».

### 6 — Деталь сделки (модалка)
- Основное (название/сумма/стадия), Связи, Дела по сделке (чек-лист), История.

## Состояния
Loading блок, error-стейт, пустая доска со стадиями.

## Адаптив
Доска скроллится по горизонтали; сводка переносит метрики; стрелки скрыты.

## Компоненты
BoardSummary, StageColumn, DealCard, DealForm(Modal), DealDetail(Modal), MoneyInput.
