# Страница: Дела (override Master)

**Цель:** звонки, встречи, показы, задачи с быстрым выполнением/переносом.

## Блоки

### 1 — Шапка
H1 «Дела» + caption. Primary «+ Дело».

### 2 — Сегменты (tabs-подчёркивание)
Сегодня / Ближайшие / Все — индикатор-подчёркивание бренд.

### 3 — Список (карточка-контейнер)
Строка дела:
- Чек-кружок (выполнить) слева.
- **Цветная иконка типа** (call→accent, meeting→brand, showing→warn, task→neutral).
- Инфо: заголовок + описание (ink-500).
- Тип-метка (caption, цвет типа).
- Срок (line-иконка calendar + дата).
- «Перенести» (для невыполненных).
- Выполнено → приглушённо + зачёркнуто.

### 4 — Модалки
Новое дело (Тип, Название*, Срок datetime, Описание). Перенос (новый срок).

## Состояния
Empty «Дел нет»; loading — скелетон-лист; error.

## Адаптив
≤600px: строка переносит элементы; тип-метка скрыта.

## Компоненты
SegTabs, ActivityRow, ActivityForm(Modal), RescheduleModal.
