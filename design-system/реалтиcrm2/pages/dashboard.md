# Страница: Обзор / Dashboard (override Master)

**Цель:** мгновенная сводка по агентству + быстрые переходы. Statement-подача:
крупное приветствие, большие цифры, минимум хрома.

## Лэйаут (12-колоночная сетка, вертикальный ритм 32–48px)

### Блок 1 — Заголовок-приветствие (c12)
- caption с датой (`Понедельник, 15 июня`).
- **display/H1** «Здравствуйте, {Имя}» (Cormorant, крупно).
- Подзаголовок-описание (ink-500).
- Нет тяжёлого hero-фона — чистый воздух (exaggerated minimalism).

### Блок 2 — KPI-строка (3× c4)
- Три stat-карточки: Сделки, Клиенты, Объекты.
- Каждая: line-иконка (тонкая), caption-лейбл, **очень крупная таблярная цифра** (count-up при появлении), ссылка-переход.
- Hover-поднятие, вся карточка кликабельна (cursor-pointer).
- Скелетон до загрузки; «—» если API недоступен.

### Блок 3 — Пайплайн (c8) + Дела сегодня (c4)
- **Пайплайн:** заголовок h3 + итоговая сумма (крупно, бренд). Горизонтальные бары стадий: лейбл, трек (brand-500 заливка), количество, сумма (таблярно). Анимация ширины при reveal.
- **Дела сегодня:** список (тип-бейдж, заголовок, время). Пусто → «На сегодня дел нет».

### Блок 4 — Сигнатурная «сводка-счёт» (c12, опционально)
- Тонкая карточка с фоном-линиями (как финансовый отчёт): построчно стадии, точки-лидеры, суммы; внизу — общий итог крупно.

## Состояния
- Loading: скелетоны KPI + блоков с первого кадра, текст «Загружаем данные…» при долгом ответе.
- Empty пайплайна → стадии с нулями (не пустой экран).

## Адаптив
≤1000px: KPI 2-в-ряд → ≤600px 1-в-ряд; блок 3 в стек.

## Компоненты
StatCard, Pipeline, TodayList, Ledger, AnimatedNumber.
