# Страница: Вход / Регистрация (override Master)

**Цель:** дать доступ в систему; первое впечатление о бренде. Паттерн скилла
«statement / negative space» → крупное утверждение + минимум полей.

## Лэйаут
Полноэкранный сплит 1.1 / 1 (на ≤820px — одна колонка, арт скрыт).

### Блок A — Statement (левая, бренд-зона)
- Фон: тёмный teal `--brand-700`, тонкая бренд-сетка + один мягкий бренд-градиент; внизу — процедурный силуэт города (SVG), редкие «горящие окна».
- Контент: лого (знак-окно), **display-заголовок** в 1–2 строки («Недвижимость под контролем»), короткий подзаголовок, 3–4 строки-преимущества с line-иконками.
- Низ: тонкая линия + строка доверия («Защищённый доступ по ИНН»).
- Параллакс фона за курсором (≤6px), уважает reduced-motion.

### Блок B — Форма (правая)
- caption «Вход в систему» → h2 «С возвращением».
- Поля (стек, лейбл сверху): ИНН агентства, Логин, Пароль.
- Primary-кнопка во всю ширину; состояние busy → «Входим…», блокировка.
- Ссылка-переключатель на регистрацию.

## Регистрация
Та же арт-зона; форма шире (2 колонки на десктопе): Название агентства, ИНН,
Телефон, ФИО владельца, Email, Логин, Пароль. Инлайн-валидация (ИНН 10/12 цифр,
email-маска, пароль ≥6 буквы+цифры), общий баннер ошибки, многошаговый busy-текст.

## Состояния
- Ошибка входа → toast (низ-право).
- Валидация полей → текст под полем `--err`.

## Адаптив
≤820px: арт-зона скрыта, форма по центру на canvas, лого сверху.

## Компоненты
AuthShell (арт+фон), BrandLogo, Field, Button.
