# Страница: Сотрудники (override Master, manage-only)

**Цель:** команда агентства, роли, активность; заведение учёток.

## Блоки

### 1 — Шапка
H1 «Сотрудники» + caption «вход по ИНН + логин + пароль». Primary «+ Сотрудник» (manage).

### 2 — Тулбар-фильтр
Поиск (имя/логин/email/телефон) + селект роли.

### 3 — Таблица → карточки на мобиле
Колонки: Сотрудник (аватар с кольцом роли + имя), Логин (mono), Контакты (иконки mail/phone), Роль (селект для не-owner / бейдж), Статус (Активен/Отключён), Действия (Изм. / Откл.|Вкл.).
- Кольцо аватара: owner→brand-gold-акцент, admin→brand, иначе нейтраль.

### 4 — Форма (модалка)
Имя*, Логин* (3–50, латиница), Пароль* (≥6), Email*, Телефон*, Роль, Комментарий.
Полная инлайн-валидация; при создании — пояснение про учётку.

## Права
Видна только owner/admin (роутер-guard). Роль owner не редактируется/не назначается.

## Состояния
Empty / «не найдено» + сброс; loading-скелетон; error.

## Компоненты
EmployeeTable, EmployeeForm(Modal), Avatar(role-ring).
