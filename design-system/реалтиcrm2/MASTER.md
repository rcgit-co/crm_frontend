## 0. Резюме направления (что выбрал скилл)

| Параметр | Значение от скилла | Реализация в коде |
|---|---|---|
| **Стиль** | Exaggerated Minimalism — крупная типографика, высокий контраст, негативное пространство, statement-подача | да, адаптировано под рабочий интерфейс |
| **Палитра** | Trust teal + professional blue: `#0F766E` / `#14B8A6` / CTA `#0369A1`, фон `#F0FDFA`, текст `#134E4A` | да |
| **Типографика** | Cinzel (заголовки) + Josefin Sans (текст) — luxury real estate | ⚠️ оба без кириллицы → подставлены кириллические аналоги (см. §3) |
| **Эффекты** | `clamp(3rem,10vw,12rem)`, тонкий трекинг, много воздуха | да, в безопасных для UI рамках |
| **Паттерн** | Before-After Transformation | переосмыслен как «пустое → наполненное» состояние разделов |

### Принципы
1. **Меньше, но крупнее.** Один акцент, много воздуха, крупные заголовки-утверждения.
2. **Контраст вместо украшений.** Границы и типографика, а не тени и градиенты.
3. **Данные — герой.** Цифры и статусы читаются мгновенно (таблярные цифры, чёткая иерархия).
4. **Спокойный ритм.** Модульная сетка 8px, секции дышат (48–96px).
5. **Доступность по умолчанию.** Контраст ≥ 4.5:1, видимый фокус, тач-цели ≥ 44px.

## 1. Цвета (светлая тема — основная)

```
--brand-700:   #0B5E57   /* нажатие, тёмный бренд */
--brand-600:   #0F766E   /* PRIMARY — бренд/CTA-фон */
--brand-500:   #14B8A6   /* secondary, прогресс, акценты */
--brand-100:   #D6F2EE   /* мягкие подложки бренд */
--accent-600:  #0369A1   /* профессиональный синий — ссылки/инфо-CTA */
--accent-100:  #DCEEF8

--ink-900:     #0B1B19   /* основной текст (≈ near-black с тилом) */
--ink-700:     #134E4A   /* заголовки/тёмный текст (skill text) */
--ink-500:     #43615C   /* вторичный текст */
--ink-400:     #5E756F   /* подписи, ≥4.5:1 на canvas */

--canvas:      #F0FDFA   /* фон приложения (skill background) */
--surface:     #FFFFFF   /* карточки/панели */
--surface-2:   #F4FBF9   /* вторичная поверхность */
--line:        #DCEAE6   /* границы */
--line-strong: #C3DAD4

--ok:    #15803D  --ok-bg:   #DCFCE7
--warn:  #B45309  --warn-bg: #FEF3C7
--err:   #B91C1C  --err-bg:  #FEE2E2
```

**Семантика:** бренд-teal — действие/прогресс; синий — ссылки/информация; зелёный/янтарь/красный — только статусы. Никаких декоративных градиентов; допускается один тонкий бренд-градиент в hero.

**Тёмная тема** — опциональна (вторая итерация). База: canvas `#08110F`, surface `#0E1A18`, ink `#E6F2EF`, brand-500 как акцент. В этой ревизии — светлая тема.

## 2. Сетка и пространство

- **Базовый юнит 8px.** Шкала: 4, 8, 12, 16, 24, 32, 48, 64, 96.
- **Контейнер:** `max-width: 1320px`, боковые поля 24–32px.
- **Сетка контента:** 12 колонок, gap 24px (на ≤1000px — 6 колонок, ≤600px — 1).
- **Ритм секций:** между крупными блоками 48–64px; внутри карточек паддинг 24–28px.
- **Воздух — часть дизайна.** Заголовки разделов отделены щедрым отступом сверху.

---

## 3. Типографика

**Выбор скилла:** Cinzel + Josefin Sans. Оба **не поддерживают кириллицу**, поэтому
для русскоязычного интерфейса берём ближайшие кириллические аналоги, сохраняя характер:

| Роль | Skill | Реализация (кириллица ✅) | Характер |
|---|---|---|---|
| Display / H1–H2 | Cinzel | **Cormorant** (600/700), верхний регистр + трекинг для «гравированного» люкса | благородный высококонтрастный serif |
| Body / UI / H3–H4 | Josefin Sans | **Manrope** (400–800) | геометричный, чистый grotesk |
| Цифры/финансы | — | Manrope, `font-variant-numeric: tabular-nums` | ровные колонки чисел |

**Модульная шкала (1.25):**
```
display  clamp(40px, 6vw, 76px) / 1.02 / -0.02em   (Cormorant, hero-утверждения)
h1       34px / 1.08 / -0.015em                    (Cormorant 700)
h2       26px / 1.12                                (Cormorant 700)
h3       18px / 1.2  (Manrope 700)
h4       15px / 1.3  (Manrope 700)
body     15px / 1.6  (Manrope 400)
small    13px / 1.5
caption  11.5px / 1.4, uppercase, letter-spacing .08em (Manrope 700) — «eyebrow»/лейблы
```
Длина строки текста — 60–75 символов.

---

## 4. Форма и движение

- **Радиусы:** контролы 10px, карточки 16px, пилюли 999px.
- **Тени:** минимальны. По умолчанию — граница `--line`. Поднятие при hover: `0 8px 24px rgba(11,27,25,.08)`. Никаких «тяжёлых» теней.
- **Границы:** 1px `--line`; активное/фокус — бренд.
- **Движение:** 180–250ms, `cubic-bezier(.2,.7,.2,1)`; анимируем `transform`/`opacity`. Hover карточек — поднятие + смена границы (без сдвига лэйаута). Scroll-reveal мягкий. Всегда учитываем `prefers-reduced-motion`.

---

## 5. Иконки и графика

- Только **SVG-линии** (Lucide), сетка 24×24, обводка 1.75–2, `currentColor`. Эмодзи запрещены.
- Декор: тонкие линии/сетка, один бренд-градиент в hero. Без стоковых картинок (используем процедурную графику — силуэт города, паттерн-сетка).
- Иллюстрация пустых состояний — минималистичная линия + одна фраза + одно действие.

---

## 6. Компоненты (контракты)

- **Button:** `primary` (бренд-фон, белый текст), `accent` (синий), `ghost`, `danger`, `sm`. Высота ≥40px, фокус-ринг, hover 200ms. Иконка слот слева.
- **Input/Select/Textarea:** 1px граница, фокус — бренд + кольцо `--brand-100`. Лейбл сверху (caption). Ошибка — `--err` + текст под полем.
- **Card / Tile:** surface, граница, радиус 16; `interactive` → hover-поднятие.
- **Badge:** пилюля; варианты `brand/ok/warn/err/neutral`; точка-индикатор.
- **Table:** заголовки caption-uppercase, зебра очень лёгкая, hover-строка бренд-100, на ≤640px → карточки «лейбл над значением».
- **Tabs:** подчёркивание-индикатор бренд (не заливка), анимация 200ms.
- **Modal:** overlay blur, surface, max-width 480/680, на мобильном — почти на весь экран, футер с действиями справа.
- **App shell:** левый минималистичный рейл (лого + навигация SVG-иконками + профиль), верхний тонкий бар (контекст + действия). На ≤900px рейл → drawer + нижняя таб-навигация.
- **KPI / Stat:** крупная таблярная цифра + caption-лейбл + дельта.
- **Empty / Loading / Error:** скелетоны с первого кадра; отдельные тексты для «пусто» и «ничего не найдено».

---

## 7. Доступность (чек-лист скилла)

- [ ] Контраст текста ≥ 4.5:1 (проверены ink-400/500 на canvas/surface).
- [ ] Видимый фокус на всех интерактивных элементах.
- [ ] Тач-цели ≥ 44px, зазор ≥ 8px.
- [ ] Последовательная иерархия заголовков h1→h6.
- [ ] Иконочные кнопки имеют `aria-label`.
- [ ] `prefers-reduced-motion` уважается.
- [ ] Адаптив проверен на 375 / 768 / 1024 / 1440px.
